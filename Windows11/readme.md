# Windows 11 без зайвих кліків

Практична книжка українською мовою для користувача Windows 11, який не є програмістом. Кожний розділ — окрема Markdown-сторінка. Матеріал розраховано на послідовне читання, практику та друк; таблиці, ілюстрації, вправи й додатки формують розгорнутий навчальний посібник орієнтовного формату близько 100 сторінок А4 залежно від параметрів друку.

> **Основний принцип:** не шукайте мишею те, що можна викликати однією сталою комбінацією. Клавіатура скорочує шлях до команди, зменшує кількість наведень і особливо економить час на повторюваних діях.

## Як користуватися книжкою

1. Читайте розділи по черзі.
2. Повторюйте дії лише на тестових файлах.
3. Розгортайте відповіді в блоках **«Показати відповідь»** після власної спроби.
4. Відмічайте чеклісти самоперевірки.
5. Тримайте [шпаргалку клавіш](appendices/keyboard-cheatsheet.md) поруч із робочим місцем.

## Про інтерактивність

Книжка не потребує JavaScript або спеціального сайту. Приховані відповіді реалізовано через HTML-елемент `<details>`, який підтримують GitHub та багато Markdown-переглядачів. У простому редакторі відповіді можуть відображатися як звичайний текст, але зміст залишиться доступним.

## Важливе застереження

Інтерфейс може трохи відрізнятися залежно від редакції, регіону, обладнання та оновлення Windows 11. Перед видаленням даних, скиданням системи, зміною шифрування або облікового запису створіть і перевірте резервну копію.
