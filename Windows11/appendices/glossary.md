# Словник простих термінів

[← До змісту](../readme.md)

| Термін | Просте пояснення |
|---|---|
| Вікно | Прямокутна область програми на екрані. |
| Фокус | Елемент, який зараз отримає натискання клавіші. |
| Ярлик | Посилання на програму, папку або файл. |
| Файл | Окремий документ, зображення, відео чи інший набір даних. |
| Папка | Контейнер для впорядкування файлів і вкладених папок. |
| Буфер обміну | Тимчасове місце для скопійованого або вирізаного вмісту. |
| Розширення файла | Частина імені після крапки, яка позначає тип, наприклад `.pdf`. |
| Обліковий запис | Особистий профіль із власними файлами й налаштуваннями. |
| Синхронізація | Узгодження актуальних версій даних між пристроями або хмарою. |
| Резервна копія | Окрема копія для відновлення після втрати чи пошкодження. |
| PIN | Код входу, зазвичай прив’язаний до конкретного пристрою. |
| Оновлення | Виправлення безпеки, помилок або функцій системи. |
| Сповіщення | Коротке повідомлення програми або Windows. |
| Контекстне меню | Перелік дій, доступних для вибраного елемента. |
| Драйвер | Системний компонент, що допомагає Windows працювати з обладнанням. |
| Фішинг | Спроба виманити пароль, код чи гроші через підроблене повідомлення. |
| BitLocker | Шифрування диска; для аварійного доступу потрібен ключ відновлення. |
