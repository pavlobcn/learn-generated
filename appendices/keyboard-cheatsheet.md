# Шпаргалка гарячих клавіш

[← До змісту](../README.md)

> Почніть із п’яти: `Win`, `Alt+Tab`, `Ctrl+S`, `Ctrl+Z`, `Win+L`. Додавайте нові комбінації поступово.

## Редагування і файли

| Клавіші | Дія |
|---|---|
| `Ctrl+C` | копіювати |
| `Ctrl+X` | вирізати |
| `Ctrl+V` | вставити |
| `Ctrl+Z` | скасувати останню дію |
| `Ctrl+Y` | повторити скасовану дію |
| `Ctrl+A` | вибрати все |
| `Ctrl+S` | зберегти |
| `Ctrl+P` | друкувати |
| `Ctrl+F` | знайти |
| `Ctrl+N` | створити новий документ або вікно |
| `Ctrl+O` | відкрити файл |

## Програми і вікна

| Клавіші | Дія |
|---|---|
| `Alt+Tab` | перейти до іншої програми |
| `Alt+F4` | закрити активне вікно |
| `Ctrl+Shift+Esc` | відкрити Диспетчер завдань |
| `Win+D` | показати робочий стіл |
| `Win+L` | заблокувати комп’ютер |
| `Win+E` | відкрити Провідник |
| `Win+I` | відкрити Параметри |
| `Win+R` | відкрити вікно «Виконати» |
| `Win+V` | історія буфера обміну після ввімкнення |

## Розташування вікон

| Клавіші | Дія |
|---|---|
| `Win+← / →` | прикріпити вікно до половини екрана |
| `Win+↑` | розгорнути вікно |
| `Win+↓` | відновити або згорнути |
| `Win+Z` | показати макети прив’язки |
| `Win+Shift+← / →` | перенести вікно на інший монітор |

## Знімки та введення

| Клавіші | Дія |
|---|---|
| `Win+Shift+S` | вибрати область знімка |
| `Win+Shift+R` | почати вибір області для запису екрана в нових версіях Ножиць |
| `PrtScn` | зробити знімок відповідно до налаштувань |
| `Win+G` | відкрити Xbox Game Bar |
| `Win+Alt+R` | почати або зупинити запис підтримуваної програми через Game Bar |
| `Win+Alt+M` | увімкнути або вимкнути мікрофон у записі Game Bar |
| `Win+.` | відкрити панель емодзі та символів |
| `Win+Space` | змінити мову введення |
| `Win+H` | голосове введення |

## Віртуальні столи

| Клавіші | Дія |
|---|---|
| `Win+Tab` | відкрити подання завдань |
| `Win+Ctrl+D` | створити робочий стіл |
| `Win+Ctrl+← / →` | перейти між столами |
| `Win+Ctrl+F4` | закрити поточний стіл |

## Доступність

| Клавіші | Дія |
|---|---|
| `Win+U` | відкрити спеціальні можливості |
| `Win++` | увімкнути або збільшити Лупу |
| `Win+Esc` | закрити Лупу |
| `Win+Ctrl+Enter` | увімкнути Екранний диктор |
| `Win+Ctrl+O` | відкрити екранну клавіатуру |

## Навігація без миші

| Клавіші | Дія |
|---|---|
| `Tab` / `Shift+Tab` | фокус уперед / назад |
| Стрілки | рух у списку, меню або тексті |
| `Enter` | відкрити або підтвердити |
| `Space` | натиснути кнопку чи змінити прапорець |
| `Esc` | скасувати або закрити |
| `Shift+F10` | контекстне меню |

> Перед `Delete`, `Shift+Delete`, скиданням чи зміною шифрування перевірте вибраний об’єкт і резервну копію.
